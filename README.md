# Bible App

Static site. To edit: open the site with ?admin on the end, tap the pencil, edit text or add photos, press Save.

## Rule for all new content

Every new or edited article, evidence entry, news item, quiz, label or other page text must be written in ALL languages the website offers (currently English and Lithuanian) before it is published. Only the Bible reader text stays in the Bible version's own language. When a language is added to the site, new content is written in it too.

How Lithuanian works: English strings live in index.html; their Lithuanian versions live in lt.js (English text -> Lithuanian text). Any new or changed English string needs a matching entry in lt.js. Verse references use Lithuanian book abbreviations (Mt, Mk, Lk, Jn, Apd, Apr ...).
